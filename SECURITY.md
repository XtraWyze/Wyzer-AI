# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead, contact the repository owner
privately through GitHub and include:

- A clear description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any suggested mitigation, if known.

You should receive an acknowledgement within seven days. Please allow time for a fix before publicly
disclosing the issue.

## Safe reports

Do not include API keys, passwords, personal files, screenshots containing private data, or other
sensitive material in a report.
